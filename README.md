BMI Calculator (Java Swing)

A simple desktop BMI (Body Mass Index) Calculator built using Java Swing. This application allows users to calculate their BMI using either Metric (kg, m)or Imperial (lbs, in) units through a clean and user-friendly graphical interface.

Features

*  Select between Metric and Imperial unit systems
*  Input fields for weight and height
*  Instant BMI calculation with a button click
*  Displays BMI value and corresponding health category
*  Styled UI with a modern color theme using Java Swing
*  Error handling for invalid inputs
